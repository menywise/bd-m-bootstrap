## 1. EN 1 MINUTE — CE QUE DB&M EST (V2.2)

**DB&M (Des Blocs & Moi)** est un systeme de transmission du savoir operatoire pour les equipes de bloc.

Bascule paradigmatique actee session #113 :

> **DB&M ne transmet pas. DB&M structure et met a disposition.**
> **Push -> pull. L'apprenant edifie. La matiere est la.**

L'IBODE qui ouvre DB&M la veille ou le matin **PRELEVE ce dont elle a besoin** dans une matiere structuree — elle n'est pas abreuvee de contenu descendant. L'IBODE qui sort de salle peut **transmettre** ce qu'elle a appris en posant ses pierres dans le chantier commun.

**Finalite unique** : ameliorer la securite du patient par la transmission du savoir operatoire — non par diffusion descendante, mais par **mise a disposition d'une matiere structuree** que chaque QUI vient prelever selon son besoin, son rythme, sa situation.

**Mission DB&M V0.6 (D-2026-05-03-DOCTRINE-01)** — 3 versions :
- (a) **L3 interne** : matiere structuree + caisse a outils croisee 5 axes (POURQUOI/QUOI/COMMENT/QUI/QUAND) x 4 savoirs (savoir/savoir-faire/savoir-etre/savoir-agir) x 3 familles (methodes pedago / grilles humaines / integration systemique). Instruments **invisibles a l'utilisateur** (cf. INTERDIT-WORDING-METHODES-01).
- (b) **Externe individuelle "tu"** : "Batis ton parcours pierre par pierre. C'est ton parcours, a ton rythme."
- (c) **Externe collective "vous"** : "L'equipe construit sa memoire collective pierre par pierre. C'est l'equipe qui batit."

**Vision DB&M V0.4 (D-2026-05-03-DOCTRINE-02)** — calage 100 k-EUR/an/grand bloc :
- 3 ans : 100 k-EUR/an / 1 grand bloc, cercle vertueux GPS-01 implemente, 2 surfaces autonomes (App Android + 1er KDP).
- 10 ans : 1 M-EUR/an (10 grands blocs x 100 k-EUR), N surfaces, contenu auto-regenerant.

**Quand DB&M intervient** :
- **Avant** l'intervention : protocole, materiel, installation, preferences chirurgien, anatomie, glossaire.
- **Apres** : transmissions, signalements, enrichissement, formation des novices.
- **Jamais pendant** : pas de check-list a cocher en salle, pas de saisie per-op, pas de scan codes-barres. *"Quand les gants sont mis, l'app reste dans la poche."*

**Pourquoi ca existe — 5 POURQUOI V0.1 (D-2026-05-03-DOCTRINE-04)** :
1. Symptome : a 7h45, des soignants competents arrivent en salle sans savoir ce qui les attend.
2. Cause directe : le savoir operatoire vit dans les tetes, pas dans un systeme consultable.
3. Cause structurelle : transmission orale epuisante (cycle toxique 6 etapes) + chaine 12+ intervenants nommant chaque chose differemment.
4. Cause systemique : aucun outil ne fait le pont entre standards officiels et vraie vie de chaque bloc — le SIH gere l'administratif, OPTIM le programme, le savoir operatoire entre les deux est orphelin.
5. **Cause racine : conjonction rare exigee** : 20 ans terrain IBODE + lecture systemique standards + discipline editoriale invisible (caisse a outils) + modele economique soutenable. **DB&M est cette conjonction.**

**Combien ca vaut** : pour un bloc reference (30 ETP, 8 800 interv/an), le cout de **NE PAS l'avoir** (CNP) est **900 k-EUR - 2,8 M-EUR/an** reparti sur 6 postes (DMI, never events, turnover, picking, formation, gaspillage). A 100-300 k-EUR/an, **ROI >= x4,5**. Source : `00_GOUVERNANCE/00_SOCLE_TERRAIN_PRICING_V1_1_0.md`.

> **Note historique** : le projet s'appelait BDB (Bible de Bloc) jusqu'en session #113. Le nom DB&M reflete mieux la posture "ecosysteme humain comme matiere premiere" + "acteur de ton parcours". Prefixes techniques `bdb_*` (tables L1) inchanges.
