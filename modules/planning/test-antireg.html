Serveur local requis

Ce fichier est ouvert directement (file://). Les tests qui lisent les fichiers source (CSS, JS) ne peuvent pas fonctionner sans serveur local — c'est une restriction de sécurité du navigateur.

Solution — ouvrir un terminal dans le dossier FRONT, puis taper :

Étape 1 — Ouvrir CMD dans le dossier FRONT

Explorateur de fichiers → dossier FRONT → cliquer sur la barre d'adresse → taper cmd → Entrée

Étape 2 — Lancer le serveur (copier-coller dans CMD, PAS dans la fenêtre Python)

Étape 3 — Ouvrir Chrome à cette adresse : http://localhost:5500/test-antireg.html

Ne pas taper la commande dans la fenêtre Python (>>>) — CMD ou PowerShell uniquement.
