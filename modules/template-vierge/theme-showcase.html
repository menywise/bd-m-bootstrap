8. Anti-patterns INTERDITS

1. CSS inline
INTERDIT <div style="color:red">
CORRECT <div class="text-danger">
2. JS inline
INTERDIT <button onclick="...">
CORRECT addEventListener('click')
3. Mix icons
INTERDIT <i class="fa fa-star">
CORRECT <i class="bi bi-star">
4. Gradient custom header
INTERDIT background: linear-gradient(...)
CORRECT class="doc-header-primary"
5. Copyright obsolete
INTERDIT © 2025
CORRECT © 2026
6. Scripts hors head
INTERDIT </head><script>...
CORRECT Scripts DANS head
Audit automatique : Ces anti-patterns sont detectes par auditor_v321.html. Score impacte de -5 a -15 points par violation.
