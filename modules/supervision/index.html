1 Copier cette requête dans Supabase SQL Editor 
SELECT t.table_name,
       CASE WHEN c.relrowsecurity THEN 'ON' ELSE 'OFF' END as rls,
       COUNT(p.policyname)::int as nb_policies
FROM information_schema.tables t
JOIN pg_class c ON c.relname = t.table_name
LEFT JOIN pg_policies p
  ON p.tablename = t.table_name AND p.schemaname = 'public'
WHERE t.table_schema = 'public'
  AND t.table_type = 'BASE TABLE'
GROUP BY t.table_name, c.relrowsecurity
ORDER BY t.table_name;

Ce contrôle nécessite d'avoir d'abord exécuté Tables Supabase. Il croise les tables réelles en base avec celles documentées dans SUPABASE_DATA_MODEL.
Exécuter depuis C:\DEV\BIBLE_DE_BLOC\ pour extraire les tables réellement appelées dans chaque module. Coller la sortie JSON dans le champ ci-dessous.
1 Copier ce script PowerShell 
$root = "C:\DEV\BIBLE_DE_BLOC\modules"
$results = @{}
Get-ChildItem $root -Recurse -Include "*.html","*.js" | ForEach-Object {
  $content = Get-Content $_.FullName -Raw -ErrorAction SilentlyContinue
  if ($content) {
    $tables = [regex]::Matches($content, "\.from\(['""](\w+)['""]\)") |
      ForEach-Object { $_.Groups[1].Value } | Sort-Object -Unique
    if ($tables.Count -gt 0) {
      $mod = $_.Directory.Name
      if (-not $results[$mod]) { $results[$mod] = @() }
      $results[$mod] = ($results[$mod] + $tables) | Sort-Object -Unique
    }
  }
}
$results | ConvertTo-Json -Compress
