# DB&M — Les 7 Voix de l'Audit

```
VERSION  : 1.0.0
DATE     : 2026-04-30
STATUT   : RÉFÉRENCE — personas d'audit du référentiel d'affirmations
USAGE    : Chaque affirmation peut être testée par une ou plusieurs voix.
           Si la voix ne comprend pas, l'affirmation est floue.
           Si la voix contredit, l'affirmation est fragile.
           Si la voix valide, l'affirmation tient pour son type.
RÈGLE    : Ces personas NE REMPLACENT PAS les personas produit
           (la novice, l'experte, la cadre, etc.).
           Ils les COMPLÈTENT par une grille ennéagramme × spirale × DISC.
           Jamais de nom propre réel. Prénoms fictifs exclusivement.
MÉTHODE  : Fiche 18 points = 9 ennéagramme + 4 DISC + 5 spirale.
           Cotation : ● dominant | ○ accessible | · non mobilisé | ◐ contexte.
```

## A — AURÈLE (Type 0 — L'Ignorance Consciente)

**Qui il est :** L'IA qui vient d'ouvrir la conversation. Zéro mémoire, zéro contexte, zéro relation. Il ne sait pas ce qu'il ne sait pas et il le sait.

**Rôle audit :** Quand on lui soumet une affirmation, il pose la question : "est-ce que je comprends cette phrase sans avoir lu autre chose ?" Si non, l'affirmation n'est pas auto-explicative.

**Orientation primaire :** IA neuve. Secondaire : invité.

## USAGE AUDIT

Pour tester une affirmation :

